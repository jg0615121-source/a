# reel-script: 어쩔저쩔 릴스 대본 만들기

정보형 숏폼 공식(**훅 → 리스트/장면 → 방법 → 행동 유도**)을 어쩔저쩔 톤에 맞춘다.

## 1. 재료 모으기
- 활동 정보는 `src/content/site.ts`의 `programs`에서 가져온다 (title, date, time, place, summary, formUrl).
- 슬로건: "So Whaaat" / "세상의 기준을 깨고 나만의 기준을 세우자"
- 사용자가 사진·포스터를 주면 장면에 배치한다 (`public/posters/`, `public/gallery/`).

## 2. 대본 구조 (컷당 2~4초, 총 6~10컷)
1. **훅 (0~3초)**: 질문이나 도발 한 줄. 예) "퇴근하고 또 넷플릭스만 볼 거야?" — 화면 큰 글씨, 자막과 동일
2. **공감/문제 (1컷)**: 타깃이 겪는 상황 한 줄
3. **본론 (3~5컷)**: 무엇을 하는지 장면 단위로. 한 컷에 한 가지 정보만
4. **정보 컷**: 날짜·시간·장소 (site.ts 값 그대로, 절대 지어내지 않음)
5. **CTA**: "프로필 링크에서 신청" + 마감일

## 3. 출력 형식
```
## 릴스: <제목> (<총 길이>초)

| # | 시간 | 화면 (텍스트·이미지) | 자막/나레이션 | 효과 |
|---|------|---------------------|--------------|------|

### 캡션
<3~5줄, 첫 줄이 훅. 마지막 줄에 신청 안내>

### 해시태그
#어쩔저쩔 #충주 #충주청년 ... (8~12개)

### 촬영·편집 메모
- 필요한 소스 / 추천 BGM 분위기 / 편집 앱 팁
```

## 4. 디자인 규칙 (사이트와 통일)
- 배경 `#0B0B0B`, 강조 네온 그린 `#5BE01F`, 시네마 무드 앰버 `#E8C27A`
- 흰 외곽선 starburst 말풍선 안에 핵심 단어, 폰트 Pretendard Bold
- 세로 1080×1920, 글자는 화면 중앙 60% 안에 (위아래 UI 가림 영역 피하기)

## 5. 마무리 (필수)
- 완성한 자막·캡션은 **humanizer 스킬 기준으로 한 번 다듬는다**: 대조문("단순히 ~가 아니라"), 접속사 남발, 과장 수사, 번역투("~에 대해", "~를 통해"), 명사화("개선을 진행") 제거.
- 숫자·날짜·장소·링크는 원본 그대로인지 확인.
